01

The six app designs

Complete single-file prototypes. Light and dark, keyboard and mouse, responsive from 320 px to desktop, no build step — double-click any of them. Each runs the full flow: sign in with the pre-filled demo credentials, pick a workspace, then use it. These are six different products, not six colour schemes: the point is to pick a direction. What changed in each ›

Familiar

ChatGPT

The layout everyone in the building already knows. Narrow sidebar, centred transcript, pill composer, model picker where ChatGPT puts it.

Signature: zero learning curve — and no global header at all.

Considered

Claude

Warm paper light mode, soft charcoal dark, editorial spacing. Projects sit above history in the sidebar.

Signature: a split artifact panel — diagrams, docs and code open beside the chat.

Provable

Sovereignty

The reason to buy Magna instead of ChatGPT, made visible. Instrument-panel density, semantic green and amber doing real work.

Signature: click any answer → its residency receipt, down to the signed hash.

Ready

Launchpad

The home screen is the product. Status not slogan, resume cards, starters built from what you have actually connected.

Signature: the / menu for skills and MCPs, and a real ⌘K palette.

Grounded

Digital twin

Provenance first. Every answer states which of your systems fed it — and which relevant one stayed silent.

Signature: the context rail — 7 connected · 6 partial · 3 missing, live.

Horizon

Futuristic

A thread is a graph, not a scroll. The answer sits centre; its sources, artifacts and follow-ups fan out along connection lines.

Signature: spatial canvas with live GPU telemetry — and a List toggle that flattens it.
