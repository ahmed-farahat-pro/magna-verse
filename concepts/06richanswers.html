What changed & why

The audit covered the shell. This covers the thing inside it — the answer itself, which is where the product currently breaks hardest.

1

Render the maths

Today: ask for integrals and you get $\int x^3 , dx$ as literal text, twenty times in a row.
Now: KaTeX for inline and display maths. Any technical or engineering seat is unusable without this.

2

Draw the diagram

Today: “I'll sketch a visual flowchart” produces box-drawing characters that break on any width change.
Now: Mermaid → real SVG, with copy-source, export and full-screen.

3

Frame the code

Today: a bare rectangle — no language, no filename, no copy.
Now: language header, copy, wrap, run, download. Copy is the most-pressed button in every chat product.

4

One action row, at the bottom

Today: a lone share icon floats on its own line below the bubble and collides with the scroll.
Now: Copy full message · Retry · Export · Share, in a single anchored row.

5

Name the models properly

Today: “Latest Kimi”, “Latest Qwen”, “Latest DeepSeek”.
Now: Kimi K2 Instruct · 1T MoE. Buyers evaluating a sovereign stack need the actual weights, version and size.
