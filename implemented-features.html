01

Chat, Canvas & Model view

The core loop, plus a right-side panel that opens beside the chat — not a new tab.

Per-thread model & sovereignty picker

Model and tier live above the transcript, not in a global header — click Kimi K2 Instruct or the Private pill in the threadbar. Each model shows what it's actually good for (long context, code, Arabic, speed), and switching sovereignty tier from Private to Public triggers a guardrail modal naming the exact internal files at risk before it lets you.

Why it matters: you never guess which model is answering or where your data is running — both are always one glance up.

Canvas + Model view panel

Click Canvas in the threadbar to open a right-side panel with two tabs. Canvas renders whatever a message produced — live HTML in a sandboxed iframe, CSV/XLSX as real sheets with tab switching and a genuine file download, or a PDF/PPTX preview with page and slide navigation. Model view renders the currently-expanded reasoning trace as an animated node graph — expand any "Thought for …" line and watch it appear live.

Switching chats automatically syncs the panel to that thread's own artifact (or clears it), so it never shows a stale file from a different conversation.

Why it matters: generated files are inspectable and downloadable in place, and the model's reasoning is visualised, not just a collapsed line of text.

Collapsed reasoning trace with real steps

Every answer's "Thought for Ns · N tools · searched N documents" line expands into the actual tool calls it made — which system, which query, how long each took — instead of a generic spinner.

02

Agents & Automations

Reached from their own sidebar items — Agents and Automations.

Agent cards with a live identity

Each agent card carries its own colour (a radial gradient wash, a glowing icon tile, a coloured top hairline) so six agents are visually distinct at a glance, plus a pulsing status dot when active. A "Who calls whom" delegation map at the bottom of the page shows exactly which agents call which — including two agents (PO Slippage Watch and Risk Research Agent) that call each other for different reasons.

Live n8n-style run trace

Press Run on any agent and its step trace animates live — nodes light up one at a time (pending → active → done) as the run progresses, using the same connected-node visual for both the live run and every past run's history. Steps where one agent delegates to another render as a distinct, clickable node that jumps straight to that agent.

Why it matters: "running" isn't a black-box spinner — you watch the actual sequence of tool calls happen.

Automation preview before it goes live

Creating a new automation now shows a preview — the shape of its first run as a node graph, plus a plain-language "Would send: …" summary — with Back to edit / Approve and create, instead of committing an automation sight-unseen.

Per-automation "View" flow

Every row in the Automations table has a View button that opens its linked agent's most recent run as the same node-graph flow, so you can see in detail what an automation actually does without leaving the page.

Skills & Connections

Connections → Skills / Tools & MCP / Channels / Audit trail.

Real connector branding

Jira, SAP S/4HANA, Primavera P6, Confluence, SharePoint/Google Drive, Slack/Teams, ServiceNow and Salesforce each show their own colour-coded brand tile instead of a generic plug icon — recognisable at a glance in the connector grid.

Outcome-oriented skills catalogue

Each skill card reads as a plain sentence with an italic example prompt, a "Try it" action, and a clear ready/needs-a-connection state — not a raw system-prompt dump. Add a skill from a catalogue template, a GitHub repo, or a pasted definition, each with its own guided flow.

Audit trail

Every approved or blocked tool call, searchable and exportable as CSV — reached directly from Connections, or via the deep link on the Governance settings pane.

04

Settings — Governance, Memory, Personality, Usage

Four panes inside Settings, alongside the existing General / Appearance / Models / Sovereignty / Connectors / Skills / Account / Help.

Governance & security

Posture stat tiles (PII masked this month, actions blocked by policy, standards checks passing), a standards checklist (SDAIA cloud policy, ISO 27001, data residency, access review), and an access & roles breakdown — with a direct link into the Audit trail.

Memory

Recall and auto-extraction toggles, a recall-limit setting, and a genuinely editable "What Magna remembers" list — each memory has a working Forget button that removes it immediately, not just a single blunt on/off switch.

Personality

Tone (Direct/Warm/Formal) and detail-level controls, custom instructions, and a worked example showing the exact same answer phrased three different ways — so the effect of the setting is visible, not abstract.

Usage & budget

A monthly budget bar, stat tiles (requests, tokens, average cost per request), and a by-model breakdown table with tier badges — the same shape of dashboard ChatGPT/Claude admins expect, built from this workspace's own data.

05

Notifications

The bell icon in the threadbar, next to Canvas.

Three-tab notification centre

Notifications — a live feed pulled from the real activity log (approvals, agent runs, automation results). Activity — background automation loops (scheduler-tick, skill-sync, housekeeping-sweep, broker-drain) each with a health status. Communication — an internal directory with online/offline presence.

Why it matters: one place to see what happened while you were away, instead of automations only surfacing results inside individual chat threads.
06

Context window indicator

The small ring next to the sovereignty pill in the threadbar.

Live, per-thread context usage

A small radial-progress ring shows the percentage of the current model's context window this thread has used, estimated from the actual transcript. Click it for the exact figure — tokens used out of the model's total window — with a note that it resets to zero on a new chat. Switching models recalculates it against that model's own window size (256K for Kimi, 128K for the others).

Why it matters: the same at-a-glance context awareness Claude gives you, computed from what's actually in the thread rather than a static number.
07

Magna Code

Its own sidebar item — a lightweight IDE surface for importing and previewing small web projects.

Claude-Code-style chat, a real terminal, and device-frame previews

Each project opens into a file tree plus three tabs: Code (syntax-aware read-only view), Chat (a genuine CLI transcript — > prompt lines, ⏺ Tool(args) calls, coloured diff blocks, Enter to send), and Terminal (a static but authentic install/dev-server boot log with a blinking cursor). The live preview renders inside a Desktop, iPhone or Android frame — complete with a status bar, notch/camera cutout and home indicator/nav bar, not just a bare iframe.

08

Chat history coverage

23 scripted threads in the sidebar, each a "happy path" demonstration of a specific capability or a specific bug now fixed — titles kept to 2–3 words, full text on hover.

Covers: schedule/cost exposure maths, vendor comparisons as real tables, contract clauses in clean prose, a 60-page PDF upload and summary, Arabic translation with a correctly-rendered Arabic PDF, an editable amendment letter, a complete (not truncated) Legal handover document, CSV outlier detection and reconciliation that reads the real attached file, a neutral (non-Magna-branded) board deck, HTML/CSV/XLSX file creation opening straight into Canvas, agent/skill/automation creation with an in-chat consent card, and a multi-agent "Gather → Analyze" chain.
