🔍

Brain Semantic Search

Type in the search bar at the top of any Brain tab. Every node matching your query lights up cyan; everything else dims. The detail panel updates to show the top match with its embedding, nearest neighbours, and source.

  • Searches labels, notes, and source metadata
  • Graph nodes highlighted/dimmed in real-time
  • Results summary with count and top matches
  • Top result auto-selected in detail panel

How it works

The search index is built lazily from BRAIN_NODES on first query. Each node is scored by label match (10 points), note match (6 points), source match (3 points), and partial word matches (3/1.5 points). The top 20 matches are highlighted; the rest dim to 10% opacity.

Try: "rebar delivery", "GC-8", "exposure", "board pack", "standby rate"
